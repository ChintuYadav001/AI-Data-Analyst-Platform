Data Processing Core

DuckDB Vectorized OLAP + Apache Parquet Storage

In-process columnar architecture completely replacing slow in-memory DataFrame scanning

Apache Parquet Storage Advantages

  • • 60–80% Memory Footprint Reduction: Snappy compression stores columns densely on disk.
  • • < 1ms Metadata Inspection: Schema, total rows, and min/max chunk stats read without scanning rows.
  • • Deterministic SHA-256 Hashing: Every upload is hashed at byte level for instant cache hits and deduplication.
  • • Column Projection & Pruning: Queries only deserialize the exact columns referenced in the query.

DuckDB Vectorized OLAP Engine

  • • Vectorized SIMD Execution: Processes memory in 2,048-element CPU register chunks.
  • • Zero Python Memory Copy: Scans Parquet directly from disk without Pandas object creation.
  • • Multi-Column Moments in < 45ms: Computes COUNT, AVG, MIN, MAX, STDDEV on 1M rows in milliseconds.
  • • Read-Only Analytical Isolation: Operates strictly in read-only mode, guaranteeing safe concurrency.
